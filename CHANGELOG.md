## [1.0.0](https://github.com/G0d0v/remnawave-installer/releases/tag/v1.0.0) — 2026-11-14

### Added

- Четыре сценария установки Remnawave через мастер G0d0v.
- Reality Vision, собственный selfsteal-домен и три темы сайта.
- Домены панели и подписок, Caddy и продление TLS.
- Привязка существующего ShopBot на локальном или отдельном сервере с SQLite backup.
- Возобновление установки, PostgreSQL backup/restore, обновление с откатом, ежедневные копии и диагностика.
- CLI-команды для логов, BBR, защиты API, управления сервисами и удаления.
- README со снимками фактического интерфейса и Linux CI.

### Security

- Случайные секреты, раздельные API-токены, закрытые порты БД, проверка доменов и архивов.
- Ограничение API ноды по источнику, включая IPv6, и восстановление правил до запуска Docker.
- Загрузка runtime из закреплённого релиза с проверкой SHA-256.
